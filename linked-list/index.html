如何理解链表？

          
位置从 0 开始。插入允许位置 0 到长度，删除允许位置 0 到长度减 1。查找返回第一个匹配位置，未找到返回 -1。

          
C 示例用 Node 结构体保存 value 和 next 指针；Node **link 指向 head 或前驱的 next 字段，因此头部和中间插入／删除可统一处理。malloc/free 展示节点分配／释放，N1 等仅为可视化身份标识，不是真实内存地址。

          
反转时先保存后继，再将当前节点的 next 指向前驱，最后更新 head。中间状态可能出现暂时未从 head 连通的节点，仍会保留显示，避免隐藏指针变化。

          
左侧 C 代码用于教学展示，浏览器由 JavaScript 模型模拟相同操作并同步高亮，不编译执行 C。定位前驱、查找和反转需 O(n)，修改连接为 O(1)；演示限制最多 12 个节点。字符串最多 12 字节，界面值用于演示，不模拟 C 的字符编码和分配失败。
