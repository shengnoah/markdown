用 Xianbao 打造更专注的 Markdown 写作体验

Xianbao 是一个面向读者和写作者的极简主义 Markdown 编辑器与阅读器。它希望把注意力从复杂的界面、频繁的模式切换和 Markdown 源码符号中解放出来，让用户回到写作本身。

为什么需要更专注的 Markdown 编辑器

传统 Markdown 编辑器常常把“源码编辑”和“预览效果”分成两个区域。对于新用户来说，这会带来额外的理解成本；对于长期写作者来说，也会让视线在编辑区和预览区之间不断切换。

Xianbao 的目标是提供一种更自然的体验：在输入时实时呈现清爽、已渲染的内容，让写作者始终沉浸在文本中。

核心体验

无缝实时预览

Xianbao 移除了预览窗口和模式切换。你可以直接在干净的画布中写作，并在输入时获得即时反馈。标题、引用、列表和代码块都会以更接近最终阅读状态的方式呈现。

专注写作

对于长文档写作，专注模式和打字机模式可以减少干扰。当前段落、句子或光标所在区域会更加突出，让你把注意力集中在正在创作的内容上。

丰富的 Markdown 能力

Xianbao 支持常见 Markdown 语法，并扩展了表格、数学公式、图表、脚注和带语法高亮的代码块等能力。无论是写技术文档、学习笔记，还是整理文章草稿，都能保持高效。

灵活导出

完成写作后，你可以将文档导出为 PDF、HTML、Word、OpenOffice、RTF、epub 等多种格式，方便在不同平台和场景中分享。

适合哪些人使用

  • 内容创作者：需要一个简单、安静、稳定的写作环境。
  • 技术作者：需要 Markdown、代码块、表格和文档结构支持。
  • 学生与研究者：需要整理笔记、论文草稿和阅读摘录。
  • 团队文档维护者：需要将文档导出为多种格式并保持结构清晰。

设计风格

当前网站采用明亮的多巴胺蓝色作为主视觉色调，导航 logo、下载按钮、卡片悬停阴影和关键交互状态都保持统一的蓝色风格。这种配色比传统绿色更轻快，也更适合突出年轻、清爽和高效的产品气质。

总结

Xianbao 不是为了堆叠复杂功能，而是为了让 Markdown 写作更顺滑、更专注、更接近最终阅读体验。它把工具退到背景，把内容放到中心，让每一次写作都更加自然。
