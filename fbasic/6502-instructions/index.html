1. 寄存器与命名规律

寄存器总览

6502 只有 6 个寄存器——正是这种极简设计让 NES 的 CPU 高效而强大：

寄存器 全称 位数 作用
A Accumulator 累加器 8 唯一的通用运算寄存器，数据中转站
X Index 变址寄存器 8 循环计数、数组下标
Y Index 变址寄存器 8 第二个变址寄存器，配合间接寻址
S Stack Pointer 栈指针 8 指向硬件栈顶（$0100-$01FF）
PC Program Counter 程序计数器 16 下一条指令的地址
P Processor Status 状态寄存器 8 标志位集合（N V - B D I Z C）

累加器 A —— 数据中转站

一切算术/逻辑运算只能在 A 中进行；内存之间不能直接传送数据，必须经过 A：

变址寄存器 X / Y —— 计数器与下标

两个独立的 8 位寄存器，三大用途：

X/Y 功能基本相同。惯例：X 做数组下标，Y 配合 (zp),Y 寻址。

栈指针 S —— 硬件栈管理员

  • 6502 硬件栈固定在内存 $0100-$01FF（256 字节）
  • S 保存栈顶位置的低字节（高字节恒为 $01）
  • 栈向下增长：压栈 S 减 1，出栈 S 加 1
  • JSR/RTS/PHA/PLA/中断自动操作栈，无需手动管理
  • 开机必须初始化：

程序计数器 PC —— 执行位置跟踪器

  • 16 位寄存器，永远指向”下一条要执行的指令”
  • 顺序执行时自动递增（按指令长度）
  • 所有跳转的本质都是修改 PC：
操作 对 PC 的影响
顺序执行 自动 + 指令长度
JMP $C000 PC ← $C000
JSR / RTS 返回地址入栈 / 出栈
BNE loop 条件成立时 PC ← loop

状态寄存器 P —— 标志位集合

P 的每一位是独立的标志，运算指令自动设置它们，分支指令根据它们决定跳转：

位 标志 名称 置 1 的条件
7 N Negative 负数 结果最高位为 1（负数）
6 V oVerflow 溢出 有符号运算溢出
5 — （未用） 恒为 1
4 B Break BRK 软中断指令
3 D Decimal 十进制 BCD 模式（NES 不用，开机 CLD 清 0）
2 I Interrupt 中断禁止 IRQ 禁用（SEI 置 1 / CLI 清 0）
1 Z Zero 零 结果为 0
0 C Carry 进位 加法进位 / 减法无借位 / 移位移出

条件分支的硬件基础——CMP 比较后看 Z 和 C 标志：

例：LDA = LoaD Accumulator（装入累加器）

2. 数据传送指令

最常用的指令组，占程序中大部分篇幅。

LDA / LDX / LDY — 读入

指令 全称 作用
LDA LoaD Accumulator 累加器 A ← 数据
LDX LoaD X register 变址寄存器 X ← 数据
LDY LoaD Y register 变址寄存器 Y ← 数据

STA / STX / STY — 写出

指令 全称 作用
STA STore Accumulator 内存 ← 累加器 A
STX STore X register 内存 ← 变址寄存器 X
STY STore Y register 内存 ← 变址寄存器 Y

注意：LDA/STA 没有”立即寻址的 STA”——立即数只能作为源，不能作为目标

TAX / TXA / TAY / TYA — 寄存器间传送

指令 全称 作用
TAX Transfer A to X X ← A
TXA Transfer X to A A ← X
TAY Transfer A to Y Y ← A
TYA Transfer Y to A A ← Y

TSX / TXS — 栈指针传送

指令 全称 作用
TSX Transfer S to X X ← 栈指针 S
TXS Transfer X to S 栈指针 S ← X

3. 算术运算指令

所有运算都在累加器 A 中进行。

ADC — 带进位加法

ADC = ADd with Carry

SBC — 带借位减法

SBC = SuBtract with Carry

易错点：6502 减法前要 SEC（不是 CLC），因为 C=1 表示”无借位”

16 位加减法（进位链接高低字节）

INC / DEC — 内存加1/减1

指令 全称 作用
INC INCrement 内存值 +1
DEC DECrement 内存值 -1

INX / INY / DEX / DEY — 寄存器加1/减1

指令 全称 作用
INX INcrement X X += 1
INY INcrement Y Y += 1
DEX DEcrement X X -= 1
DEY DEcrement Y Y -= 1

4. 逻辑运算指令

按位运算，结果放回累加器。

指令 全称 作用 示例
AND logical AND 按位与 and #$80 取最高位
ORA OR Accumulator 按位或 ora #$01 置最低位
EOR Exclusive OR 按位异或 eor #$FF 全部位取反

BIT — 位测试

BIT = 位测试，测试内存与累加器的公共位，不改变 A。

5. 比较与分支指令

CMP / CPX / CPY — 比较

指令 全称 作用
CMP CMPare A A 与操作数比较
CPX ComPare X X 与操作数比较
CPY ComPare Y Y 与操作数比较

比较即做减法（A - 操作数）但不保存结果，只设置标志位：

分支指令（相对跳转，范围 ±127 字节）

指令 全称 跳转条件
BEQ Branch if Equal Z=1（相等/为零）
BNE Branch if Not Equal Z=0（不等/非零）
BCS Branch if Carry Set C=1（≥/无借位）
BCC Branch if Carry Clear C=0（</有借位）
BMI Branch if Minus N=1（负数）
BPL Branch if Plus N=0（正数/零）
BVS Branch if oVerflow Set V=1（溢出）
BVC Branch if oVerflow Clear V=0（无溢出）

比较后的分支组合（最常用）

6. 移位指令

对累加器或内存单字节操作。

指令 全称 作用
ASL Arithmetic Shift Left 左移1位，bit0补0，bit7→C
LSR Logical Shift Right 右移1位，bit7补0，bit0→C
ROL ROtate Left 循环左移，C→bit0，bit7→C
ROR ROtate Right 循环右移，C→bit7，bit0→C

用途：乘除 2 的幂、逐位检测、乘法算法的核心。

7. 跳转与子程序

指令 全称 作用
JMP JuMP 无条件跳转（绝对地址）
JSR Jump to SubRoutine 调用子程序（返回地址入栈）
RTS ReTurn from Subroutine 子程序返回（地址出栈）
RTI ReTurn from Interrupt 中断返回

JSR/RTS 是 6502 的函数调用机制：JSR 把返回地址压入硬件栈，RTS 弹出并跳回。

8. 栈操作指令

6502 硬件栈固定在内存 $0100-$01FF，栈指针 S 从 $FF 递减。

指令 全称 作用
PHA PHush Accumulator A 入栈
PLA PLull Accumulator A 出栈
PHP PHush Processor status 状态寄存器入栈
PLP PLull Processor status 状态寄存器出栈

注意：6502 栈只能直接操作 A 和标志位，X/Y 不能入栈（需经 TAX→PHA 间接保存）

9. 标志位操作指令

状态寄存器 P 的标志位：Carry、Zero、Interrupt、Decimal、oVerflow、Negative

指令 全称 作用
CLC CLear Carry C=0（加法前）
SEC SEt Carry C=1（减法前）
CLI CLear Interrupt 允许IRQ中断
SEI SEt Interrupt 禁止IRQ中断
CLD CLear Decimal 关闭BCD模式（NES必做）
SED SEt Decimal 开启BCD模式（NES不用）
CLV CLear oVerflow V=0

10. 寻址方式速查

同一指令配合不同寻址方式，是 6502 汇编的核心。

寻址方式 语法示例 含义 速度
立即寻址 lda #$0A 数值 10 本身 快
零页寻址 lda $10 读内存 $0010 最短
零页,X lda $10,x 读内存 $0010+X 快
绝对寻址 lda $8000 读内存 $8000 中
绝对,X lda $8000,x 读内存 $8000+X 慢
绝对,Y lda $8000,y 读内存 $8000+Y 慢
间接索引 lda ($10),y 读”指针$10指向的地址+Y” 慢但灵活
隐含寻址 txs / rts 操作数隐含 最快
相对寻址 bne loop 跳转 ±127 字节内 快
间接寻址 jmp ($1000) 跳到”指针指向的地址” 仅JMP
