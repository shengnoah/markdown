FBASIC 与 6502 教程

欢迎来到 FBASIC 与 6502 教程！本教程带你从 BASIC 语句一路深入到 6502 汇编实现。

🎯 关于本教程

FBASIC 是一个 Family BASIC 风格的 BASIC 方言，有三个实现版本：

版本 语言 平台 状态
JS 版 JavaScript 浏览器（本站） ✅ 功能最全
C 版 C99 PC 终端 ✅ 算术表达式待完善
NES 版 6502 汇编 红白机 ROM 📐 设计中

📚 教程内容

FBASIC 语言

  • 变量与赋值 - 数值变量、字符串变量、INPUT 输入
  • 算术表达式 - 运算符优先级、左结合规则
  • 逻辑与条件 - IF/THEN 结构、六种比较运算
  • 循环结构 - FOR/NEXT、STEP 步长、循环嵌套
  • 函数 - 内置数值/字符串函数、GOSUB/RETURN 子程序
  • 数组 - DIM 声明、变址寻址的汇编本质

6502 汇编专题

  • 指令速查 - 常用指令、寻址方式、六大代码模板
  • 寻址方式详解 - 12 种寻址方式原理与场景选择
  • 结构实现 - IF/FOR 结构的汇编实现、FOR 栈机制
