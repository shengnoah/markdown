已支持语法

      

        
PRINT "TEXT"输出文字或表达式

        
CLS清屏，模拟 Family BASIC 特有命令

        
LET A = 10变量赋值，LET 可省略

        
INPUT "NAME"; N$读取用户输入

        
IF A > 3 THEN 100条件跳转或执行语句

        
FOR I = 1 TO 10循环，支持 STEP

        
GOTO 100跳转到指定行号

        
GOSUB 200调用子程序，配合 RETURN

        
LIST直接命令：列出编辑区程序

        
SYSTEM直接命令：重置模拟器状态

        
CHR$()按字符编码返回字符，例如 CHR$(65)

        
ASC()返回字符串首字符编码

        
LEN()返回字符串长度

        
LEFT$()返回字符串左侧指定长度

        
RIGHT$()返回字符串右侧指定长度

        
MID$()返回字符串中间片段

        
RND()返回 0 到 1 之间的随机数

        
INT()返回向下取整后的整数

        
ABS()返回绝对值

        
VAL()将字符串转换为数字

        
STR$()将数字转换为字符串
