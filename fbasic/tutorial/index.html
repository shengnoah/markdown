FBASIC 教程 — 从 BASIC 语句到 6502 汇编

FBASIC 是一个 Family BASIC 风格的 BASIC 方言，有三个实现版本。
本教程介绍语言本身，并深入讲解 IF 和 FOR 结构对应的 6502 汇编实现——这是通往 NES 版解释器的必经之路。

BASIC 条件 6502 实现 分支指令 跳转含义
A = B lda A / cmp B beq 相等跳
A <> B lda A / cmp B bne 不等跳
A < B lda A / cmp B bcc 小于跳
A >= B lda A / cmp B bcs 大于等于跳
A > B lda A / cmp #B+1 bcs 大于跳（技巧：比B+1）
A <= B lda A / cmp #B+1 bcc 小于等于跳

原理：CMP 执行减法 A - B 但不保存结果，只设置标志位。BCC（进位清零跳转）= 有借位 = A < B；BEQ（零标志）= A = B。

5.6 解释器的 FOR 栈机制

FBASIC 解释器（JS/C 版）用栈保存每个活跃循环的状态，支持嵌套：

NES 版设计：FOR 栈帧 7 字节 [变量名][终值高][终值低][步长高][步长低][返回地址高][返回地址低]，最多 4 层嵌套，放在 $0700-$077F。

为什么需要栈：嵌套循环 FOR I ... FOR J ... NEXT J ... NEXT I 时，内层 NEXT 只操作栈顶的 J 帧，外层 I 帧在下面等着——后进先出正好匹配循环的嵌套结构。

6.5 对应的 6502 汇编

GOSUB/RETURN 直接对应 6502 的 JSR/RTS：

原理：JSR 把”下一条指令的地址”压入 $0100-$01FF 的硬件栈再跳转；RTS 弹出该地址返回。这与 BASIC 解释器用软件栈（gosub_stack）保存”下一行行号”是同一思想——调用者位置入栈，返回时出栈。

内置函数在 NES 版的实现则是查表 + 跳转：函数名 → 函数表索引 → jmp (函数表) 间接跳转到对应例程。
