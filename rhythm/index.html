节奏敲击

使用说明：这是一款 8-bit 风格的节奏敲击游戏——背景音乐由 Web Audio 实时合成 （方波旋律 + 三角波低音 + 鼓点），音符会随音乐节拍沿四条轨道掉落。 当音符到达底部判定线时，按下对应轨道的按键 D / F / J / K 敲击：
踩点越准得分越高——PERFECT（±50ms，100分）、GREAT（±100ms，70分）、 GOOD（±160ms，40分）；错过节拍即 MISS，中断连击并损失一条生命，生命耗尽演奏中断。
开始前可选择演奏速度（慢速 80 / 中速 100 / 快速 120 BPM，速度越快音符越密）； 连续击中可获得连击加成；一首曲子演奏完成后按准确率获得 S / A / B / C / D 评级，最高分按速度分别记录。 按 Esc 或点击「暂停」可随时暂停（音乐与画面同步冻结、无缝恢复），🔊 按钮可开关声音。
