实现说明与差异

        
整个解释器约 4000 行 JavaScript，分为词法分析、递归下降解析器、树遍历求值器和标准库四层。协程直接复用 JS generator，因此 yield 可以穿过任意深度的 Lua 调用。

        

          
            
项目说明

          
          
            
数字统一使用双精度浮点，没有独立的 64 位整数子类型；2/1 显示为 2 而非 2.0，超出 253 的整数会损失精度；位运算通过 BigInt 模拟 64 位

            
字符串按 UTF-16 索引，中文按字符处理，string.char 接受 Unicode 码点；Lua 原生按字节索引，string.char 只接受 0–255

            
文件 IO浏览器不提供文件系统，io.read 从页面的「标准输入」读取，io.write 写入输出面板

            
模块没有 require / package；可用 load 动态执行代码

            
递归普通递归受 JavaScript 调用栈限制，约 200 层；尾调用 return f(...) 会复用栈帧，可无限递归

            
其他不支持 <close>、__gc、string.pack；goto 不做局部变量作用域的静态检查
