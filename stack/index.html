栈不是堆（Heap）

          
这里展示的是栈（Stack），也常被称为堆栈，不是堆排序中的堆。栈遵循 LIFO：Last In, First Out，后进先出。

          
入栈把值放在顶部；出栈移除顶部元素并返回；查看栈顶只读不删除。空栈出栈称为下溢，达到演示容量后再入栈称为上溢。

          
C 示例用 Stack 结构体保存字符串数组、top 和 capacity；push/pop/peek 返回 bool 表示是否成功。左侧 C 代码用于教学展示，浏览器由 JavaScript 模型模拟相同操作并同步高亮，不编译执行 C。单步执行一个栈操作。

          
常见用途包括函数调用栈、撤销操作、括号匹配和深度优先搜索。紫色边框表示栈顶，绿色表示入栈，粉色表示出栈或错误。
