COBOL 语言教程

COBOL 语言教程

欢迎来到 COBOL 语言教程！本教程基于 GnuCOBOL，从零开始带你掌握这门”古老而常青”的商业语言。

🎯 关于本教程

COBOL（COmmon Business Oriented Language）诞生于 1959 年，至今仍是银行、保险、政府等大型机核心业务系统的主力语言。本教程结合 hello.cob 与 snake.cob 两个实例项目讲解，所有代码均可在 GnuCOBOL 上编译运行。

适合人群：

  • 想学习 COBOL 的编程初学者
  • 需要维护遗留 COBOL 系统的开发者
  • 对大型机/金融系统感兴趣的技术人员

📚 教程内容

基础篇

  • 基础入门 - COBOL 简介、Hello World、四大部、固定/自由格式、编译运行
  • 数据类型与变量 - 层级编号、PIC 子句、VALUE、USAGE、常量
  • 过程部与语句 - MOVE、算术、IF、EVALUATE、PERFORM、字符串、内置函数
  • 表与数组 - OCCURS、二维表、下标与索引、变长表、SEARCH 查找

进阶篇

  • 文件处理 - 顺序文件、索引文件、相对文件、文件状态码
  • 子程序与调用 - CALL、LINKAGE SECTION、参数传递、调用 C 库函数

实战篇

  • 贪吃蛇实战解析 - 完整剖析 snake.cob 的架构、算法与实现
  • 抽出・集计・突合 - 日本业务系统三大数据处理模式（筛选/汇总/核对）

常用语句

语句 用途

COMPUTE X = A + B 复合运算
IF ... END-IF 条件
EVALUATE ... END-EVALUATE 分支

CALL "子程序" 调用
