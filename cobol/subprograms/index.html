1. 子程序概述

COBOL 支持模块化编程，一个程序可以调用另一个程序。子程序是独立编译的模块，通过 CALL 语句调用。

优势：

  • 代码复用，避免重复
  • 模块化，便于维护
  • 可跨语言调用（如调用 C 函数）

两种形式：

  1. 内部子程序：同一源文件中的多个 PROGRAM-ID
  2. 外部子程序：独立编译为 .so 或 .o 模块

7. 实战：snake.cob 调用 usleep

snake.cob 通过调用 C 库函数 usleep 实现游戏延时：

数据声明

  • PIC 9(6)：6 位数字，最大 999999 微秒
  • COMP-5：原生二进制格式，与 C 的 unsigned int 兼容

延时逻辑

分析：

  1. 分数 < 35 时，延时 = 200000 - 分数 × 4000 微秒（分数越高越快）
  2. 分数 ≥ 35 时，固定 60000 微秒（60ms）
  3. CALL "usleep" USING BY VALUE 调用 C 函数，BY VALUE 传递数值

为什么用 BY VALUE？

C 函数 usleep(useconds_t usec) 按值接收参数。若用默认的 BY REFERENCE，C 函数会收到指针而非数值，导致错误。

编译

usleep 属于标准 C 库，无需额外链接参数。
