1. 段落与节

PROCEDURE DIVISION 由段落（Paragraph）组成，段落可组织为节（Section）。

规则：

  • 段落名从 A 区开始，以 . 结尾
  • 段落内的语句从 B 区开始
  • 段落名是标签，通过 PERFORM 调用
  • 段落名不能与保留字冲突

  • 长度不匹配：字符型左对齐截断/补空格，数值型右对齐

9. 内置函数

COBOL 提供丰富的内置函数（Intrinsic Functions），用 FUNCTION 函数名(参数) 调用。

函数 说明 示例
ABS 绝对值 FUNCTION ABS(-5) → 5
MOD 取模 FUNCTION MOD(7, 3) → 1
INTEGER 取整 FUNCTION INTEGER(3.7) → 3
NUMVAL 字符串转数值 FUNCTION NUMVAL("123") → 123
RANDOM 随机数 [0,1) FUNCTION RANDOM
LENGTH 长度 FUNCTION LENGTH(WS-NAME)

10. 实战：snake.cob 的语句分析

主循环结构

分析： 先初始化，然后循环执行游戏主逻辑直到 WS-RUNNING = 0，最后显示结束信息。

方向选择逻辑

分析： 遍历 4 个方向，对每个安全方向计算到食物的曼哈顿距离，选择距离最小的方向（贪心算法）。

延时控制

分析： 分数越高延时越短（速度越快），最低 60ms。通过 CALL 调用 C 库函数 usleep。
