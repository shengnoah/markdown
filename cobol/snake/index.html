贪吃蛇实战解析

本章完整剖析 snake.cob 的实现，将前面所学知识融会贯通。

1. 游戏概述

snake.cob 是一个用 GnuCOBOL 实现的贪吃蛇游戏，特点：

  • 自动寻路：蛇自动在安全方向中贪心逼近食物，无需玩家操作
  • 随机食物：食物随机刷新，不会出现在蛇身上
  • 动态速度：分数越高移动越快
  • 多种结束条件：撞墙 / 撞自己 / 占满全场 / 步数上限

游戏规则：

元素 符号 说明
蛇身 o 蛇的身体
食物 * 吃到得分 +1，长度 +1
墙壁 # 边界，撞到即结束
空地 空格 可通行区域

2. 整体架构

程序采用模块化段落设计，主流程清晰：

段落清单：

段落 职责
MAIN-PROCEDURE 主入口，控制整体流程
INIT-GAME 初始化蛇、方向、分数、随机种子
GAME-LOOP 主循环：构建网格→显示→移动→延时
BUILD-GRID 根据蛇和食物位置构建网格
SHOW-GAME 渲染游戏画面
MOVE-SNAKE 移动蛇、碰撞检测、吃食物
CHOOSE-DIR 选择最优方向（贪心算法）
TEST-DIRECTION 测试某方向是否安全
PLACE-FOOD 随机放置食物
CHECK-ON-SNAKE 检查食物是否在蛇身上
DELAY 延时控制速度
CLEAR-SCREEN ANSI 清屏

3. 数据结构设计

3.1 网格（二维表）

12 行 × 20 列的二维表，每个格子存储状态码。

3.2 蛇身（坐标数组）

  • 最多 240 节（= 12 × 20，占满全场）
  • 索引 1 是蛇头，索引 WS-SNAKE-LEN 是蛇尾
  • WS-SX/WS-SY 分别存储 x/y 坐标

4. 核心算法

4.1 初始化（INIT-GAME）

要点：

  • 蛇初始为 3 节，水平排列在 (3,6)(4,6)(5,6)
  • 用 FUNCTION CURRENT-DATE 取当前时间，截取第 9-16 位（HHMMSSss）作为随机种子
  • FUNCTION RANDOM(种子) 初始化随机数序列

4.2 方向选择（贪心算法）

算法：

  1. 遍历 4 个方向
  2. 对每个方向调用 TEST-DIRECTION 判断是否安全
  3. 安全则计算到食物的曼哈顿距离 |dx| + |dy|
  4. 选择距离最小的方向（平局时保持原方向，避免抖动）

4.3 方向安全性检测（TEST-DIRECTION）

检测两步：

  1. 边界检测：新坐标是否在 120（x）和 112（y）范围内
  2. 自撞检测：新坐标是否与蛇身（除尾节）重合

4.4 移动蛇（MOVE-SNAKE）

流程：

  1. 选方向 → 计算新蛇头坐标
  2. 撞墙检测 → 结束
  3. 自撞检测 → 结束
  4. 吃食物检测 → 加分、变长、刷新食物
  5. 身体后移（从尾到头）→ 新坐标写入蛇头

4.5 随机放置食物（PLACE-FOOD）

策略：

  1. 随机生成坐标，最多尝试 500 次
  2. 若随机失败（蛇几乎占满），则按行扫描找空位
  3. FUNCTION INTEGER(FUNCTION RANDOM * 20) + 1 生成 1~20 的随机整数

5. 显示与清屏

5.1 ANSI 清屏序列

X"1B5B324A1B5B48" 是十六进制字节序列：

字节 含义
1B ESC（转义符）
5B [
32 4A 2J（清屏）
1B 5B 48 ESC [ H（光标归位）

等价于终端命令 \033[2J\033[H。

5.2 清屏段落

WITH NO ADVANCING 抑制换行，直接输出转义序列。

5.3 渲染画面（SHOW-GAME）

要点：

  • 用 WS-LINE（22 字符）逐行拼接
  • WS-LINE(1:1) 是左墙，WS-LINE(22:1) 是右墙
  • WS-LINE(WS-J + 1:1) 用引用修改逐格填充
  • WS-SCORE-OUT 是编辑型 PIC ZZZ9，前导零显示为空格

8. 扩展练习

学完本教程后，可尝试以下扩展：

  1. 手动控制：用 ACCEPT 读取键盘输入，让玩家控制方向
  2. 难度分级：增加难度选择，调整初始速度
  3. 障碍物：在网格中随机生成障碍物
  4. 最高分记录：用文件处理保存历史最高分
  5. 彩色显示：用 ANSI 颜色序列让蛇身、食物显示不同颜色
  6. 穿墙模式：撞墙时从对面出现而非结束
  7. 更智能的寻路：用 BFS/A* 算法替代贪心，避免自困
