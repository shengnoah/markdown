无缝实时预览

专注于内容，而非语法。Xianbao 在你写作时呈现干净、已渲染的视图。

✍️

无干扰写作

不再有预览窗口或模式切换。只有你和你的文字，置身于干净的画布之中。

📐

Markdown 扩展

表格、数学公式（LaTeX）、图表、脚注、带语法高亮的代码块等等。

📄

任意导出

将文档导出为 PDF、HTML、Word、OpenOffice、RTF、epub 等多种格式。

🗂️

大纲与文件树

使用内置的文件树面板管理文件，通过大纲视图在长文档中快速导航。

🎯

专注模式

仅高亮当前行、句子或段落，让你能够专注于写作本身。

⌨️

自动配对

自动补全括号、引号和 Markdown 符号，加快你的写作流程。

精美主题

使用内置主题自定义 Xianbao 的外观，或用 CSS 打造属于你自己的主题。
